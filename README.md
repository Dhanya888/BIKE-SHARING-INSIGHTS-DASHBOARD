# Bike Sharing Insights Dashboard

## Run locally
1. Install Python 3.10+.
2. Open a terminal in this folder.
3. Install dependencies:
   `pip install -r requirements.txt`
4. Launch:
   `streamlit run app.py`

The dashboard opens in your browser and includes filters, KPI cards, a rider-share pie chart, time/day charts, weather and seasonal charts, a heatmap, scatter plots, key takeaways, and filtered-data export.

Dataset: UCI Bike Sharing Dataset (`hour.csv`, `day.csv`). The app uses `hour.csv`.
Note: this dataset predicts/analyzes bike rental demand, not road traffic congestion.
